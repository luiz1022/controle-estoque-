# 🚆 Sistema de Controle de Estoque

Sistema web desenvolvido como projeto de portfólio para demonstrar conhecimentos em **JavaScript, HTML, CSS, lógica de programação, organização de código e desenvolvimento de aplicações de gestão**.

## 🚀 Demonstração

A versão disponível neste repositório pode ser publicada gratuitamente utilizando **GitHub Pages**, permitindo que o projeto seja testado diretamente pelo navegador.

> Esta versão é uma demonstração independente, com dados fictícios executados no navegador.

## 📋 Funcionalidades

- Dashboard com indicadores de estoque
- Catálogo e inventário de materiais
- Pesquisa por código ou descrição
- Filtro por status do estoque
- Identificação de materiais abaixo do ideal
- Identificação de materiais zerados
- Registro de entradas
- Registro de saídas
- Validação de saldo disponível
- Histórico de movimentações
- Atualização dinâmica dos indicadores
- Layout responsivo para desktop e dispositivos menores

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 💡 Objetivo do projeto

O projeto foi desenvolvido para compor meu portfólio profissional e demonstrar a aplicação prática de conceitos de desenvolvimento de software em uma solução de controle e gestão de materiais.

## 🔗 Versão integrada

O projeto também possui uma versão integrada com **Google Apps Script e Google Sheets**, utilizando backend, persistência de dados, autenticação, histórico e automações.
